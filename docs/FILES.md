# Claw Dupe – File Guide

This project is a tiny Node.js + TypeScript service. Here’s what each file does and what you might edit.

- `package.json`: project manifest. Lists dependencies and scripts. Run `npm run dev` (start in watch mode), `npm run build` (compile TS to JS), and `npm start` (run built output).
- `tsconfig.json`: TypeScript compiler settings (targets modern Node, outputs to `dist`, enforces strict type checks).
- `.gitignore`: keeps `node_modules`, `dist`, and your `config.yaml` out of git.
- `config.example.yaml`: sample settings (host, port, log level). Copy to `config.yaml` and change values there.
- `src/server.ts`: main entry. Starts a Fastify web server, adds a `/health` route, wires logging, and handles clean shutdown on Ctrl+C.
- `src/config.ts`: reads `config.yaml` (or defaults) using YAML parser, provides settings to the server.
- `dist/`: compiled JavaScript output after `npm run build` (generated; safe to delete and rebuild).
- `node_modules/`: installed dependencies (generated by npm install; usually not committed).

Quick start

1. Copy `config.example.yaml` to `config.yaml` if you want custom host/port.
2. Install deps: `npm install` (already done once; redo if you clean node_modules).
3. Dev server: `npm run dev`, then open `http://localhost:3000/health` to see `{ status: "ok", ... }`.
